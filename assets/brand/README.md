# Brand assets

The Pain By Choice mark is a P whose bowl has a play button cut out of it.
The bowl is separated from the stem by a deliberate 3-unit gap.
Everything in this folder is generated by `generate.py` from one definition of
the mark's geometry, so edit that file rather than the outputs:

```bash
pip install pillow fonttools
python3 assets/brand/generate.py --font path/to/InterTight-ExtraBold.ttf
```

| File | Use |
| --- | --- |
| `svg/mark.svg`, `svg/mark-on-dark.svg` | Primary mark for light and dark backgrounds |
| `svg/mark-reverse.svg` | For use on Cut Red |
| `svg/mark-mono-black.svg`, `svg/mark-mono-white.svg` | Single colour |
| `svg/mark-small*.svg` | 24px and below: no gap, heavier stem, bigger play cutout |
| `svg/lockup-{horizontal,stacked,compact}[-on-dark].svg` | Mark + wordmark (text converted to outlines) |
| `svg/app-icon-{dark,red,light}.svg` | App icon tiles. Dark is the default |
| `png/app-icon-{16…1024}.png` | Dark app icon rasters. ≤32px use the small mark |
| `png/app-icon-{red,light}-1024.png`, `png/mark*-1024.png` | Marketing rasters |
| `favicon.ico` | 16/32/48/256 |
| `app-icon.icns` | macOS app icon |

Colours: Cut Red `#E8321F` · Ink `#141317` · Bone `#EFECE6` · Ash `#6D6A73` ·
Canvas `#1D1C22`. The wordmark is Inter Tight ExtraBold with −3.5% letter
spacing, cap height equal to the bowl. Inter Tight is under the SIL Open Font
License. The font itself is not committed, only outlines of its letters.

Rules: never close the gap, recolour the bowl, stretch or rotate the mark.
Keep empty space around it equal to one stem width on every side.
